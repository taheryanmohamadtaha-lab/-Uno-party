# UNO Party – بازی کارتی سه‌بعدی کارتونی (اندروید)

نسخهٔ ۱.۰ – **فاز ۱ و ۲**: موتور قوانین، هوش مصنوعی، میز سه‌بعدی، کارت‌ها، آواتارها، انیمیشن‌ها، صفحهٔ بازی با کامپیوتر، منو و ساخت خودکار APK.

## وضعیت واقعی پروژه
| بخش | وضعیت |
|---|---|
| موتور قوانین (۱۰۸ کارت، Skip/Reverse/+2/Wild/+4، اعتراض +4، UNO، دونفره) | نوشته شده |
| قوانین اختیاری (Stacking، 7-0، Jump-In، کشیدن تا کارت قابل بازی، تعداد کارت شروع) | نوشته شده |
| هوش مصنوعی (Easy/Medium/Hard) و ۸ شخصیت | نوشته شده |
| تست‌های Unit و شبیه‌سازی کامل بازی‌های AI | نوشته شده؛ **هنوز اجرا نشده** |
| منوی اصلی (پس‌زمینه، تغییر زبان، قوانین، درباره) | نوشته شده؛ بقیهٔ دکمه‌ها «به‌زودی» |
| **فاز ۲:** میز سه‌بعدی، کارت‌های حجم‌دار، ۹ آواتار کارتونی، انیمیشن پخش/پرتاب کارت، انتخاب رنگ Wild، اعتراض +4، دکمهٔ UNO، جلوهٔ برد، صفحهٔ تنظیم بازی (۱ تا ۳ رقیب، سختی، قوانین اختیاری) | نوشته شده؛ **هنوز روی گوشی دیده/اجرا نشده** |
| چندنفرهٔ محلی، شخصی‌سازی، تورنمنت، صدا، ذخیره و ادامهٔ بازی | فازهای بعدی |

> کد در محیط توسعه با Flutter کامپایل یا اجرا نشده است. اولین اجرای GitHub Actions اولین تست واقعی است؛
> گزارش تست در Artifact با نام `reports` ذخیره می‌شود.

## ساخت APK (بدون نیاز به دانش برنامه‌نویسی)
1. در GitHub یک مخزن جدید بسازید (مثلاً `uno-party`).
2. محتویات پوشهٔ `uno_party` را آپلود کنید (Add file ← Upload files). پوشهٔ `.github` را هم حتماً آپلود کنید.
3. به تب **Actions** بروید؛ ساخت خودکار شروع می‌شود (یا Run workflow).
4. بعد از اتمام، از پایین صفحهٔ اجرا، Artifactهای `UNO-Party-release-apk` و `UNO-Party-debug-apk` را دانلود کنید.
5. فایل ZIP را باز کنید و `app-release.apk` را روی گوشی نصب کنید (نصب از منبع ناشناس را مجاز کنید).

اگر ساخت خطا داد، متن خطا را برای من بفرستید تا رفع کنم.

## ساختار
```
lib/models        کارت‌ها
lib/rules         تنظیمات قوانین (استاندارد در برابر اختیاری)
lib/game_engine   موتور بازی (مستقل از UI)
lib/ai            هوش مصنوعی و شخصیت‌ها
lib/screens       صفحات
lib/localization  فارسی/انگلیسی
test              تست‌ها
```
